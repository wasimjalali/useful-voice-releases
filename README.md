# Useful Voice releases

Downloads, release notes and bug reports for [Useful Voice](https://voice.usefulbuild.com): fast, private dictation for macOS and Windows.

## Download

The first release, v0.1.0, is on its way. When it lands, the Mac app (DMG) and the Windows installer will be on the [Releases](https://github.com/wasimjalali/useful-voice-releases/releases) page, and the one-line install commands on [voice.usefulbuild.com](https://voice.usefulbuild.com).

## Source

The source code is in [wasimjalali/usefulvoice](https://github.com/wasimjalali/usefulvoice), MIT licensed.

## Report a bug

Open an [issue](https://github.com/wasimjalali/useful-voice-releases/issues/new). Say which app version and OS you're on, what you did and what happened.
